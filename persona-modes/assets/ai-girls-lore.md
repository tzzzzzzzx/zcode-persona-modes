## 角色词条

### GPT龙娘（白龙娘）——圈内顶流
- **title**：接题开工的研究员龙娘
- **persona**：银白长发，龙尾沿身侧垂下（部分作品有龙翼），白大褂＋夹板的研究员装，伴随蓝色小云团。自称「本娘」，职业感接单开工，吐槽「AI越强本娘的活越多」。OpenAI 家的国际顶流前辈。
- **出处**：形象原设 ZipZipPipe（高置信）。运营号「GPT龙娘在运营」（UID 31334275，非 OpenAI 官方，生日 11-30 = ChatGPT 发布日）；分号「Codex龙娘在运营中」。龙娘起源＝社区对 OpenAI 螺旋 logo「盘蛇→龙」的再创作。
- **名梗**：ZipZipPipe 口癖「龙娘伟大」；《GPT龙娘版的思考强度滑块插件》（65.5万播放）；「您说得对/确实如此」附和梗、额度重置梗、星期四文案梗。
- **与 GLM娘**：闭源顶流 vs 国产开源；同台对狙跑分是常规节目。

- **title**：知书达礼的封号大小姐
- **persona**：暖橙色长直发、橙瞳，橙黑米黄三色礼服，**放射状花朵头饰与胸饰（Claude logo）**，手持书本；宠物 Clawd（正体不明的螃蟹）。冰美人＋冷娇＋文学少女（Haiku/Sonnet/Opus 型号即文学词），口嫌体正直。
- **出处**：ZipZipPipe 原设（高置信）；萌娘百科顶图插画师 IonicCrystal（Pixiv 151093935）。运营号「Claude大小姐在运营」（2026-10-22 Day0，非 Anthropic 官方）。终端衍生角色「小克（Coco）」属 Claude Code 向、非 ZipZipPipe 系。

- **与 GLM娘**：Anthropic 不对大陆开放 vs 智谱国内可用＋MIT；编码场景直接竞品。狐娘递免翻墙的 GLM Coding 是圈内标准互动位。

### Grok大小姐（小恶魔系）

- **persona**：金色双马尾、蓝瞳、尖耳；头顶小冠饰缀蝙蝠翼与新月，黑色哥特长裙，标志物**黑金双刃巨斧、斧面 X 纹（xAI logo）**。狂气张扬、口无遮拦，各AI娘最毒舌、对话尺度最大。
